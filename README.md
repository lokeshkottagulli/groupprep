# groupprep
GroupPrep is a study and practice website for candidates preparing for the Andhra Pradesh Public Service Commission (APPSC) Group I, II, III, and IV exams. You can browse the syllabus by group, exam stage, and paper, then build a daily study plan around your exam date and available study time.

## Run locally

Start the site and its registration API with Python 3:

```sh
python server.py
```

Open [GroupPrep](http://127.0.0.1:8000/). Accounts and sign-in sessions are stored in `.groupprep/accounts.sqlite3`. Study plans and practice history are stored in the browser.
